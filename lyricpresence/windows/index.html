Windows

LyricPresence
for Windows

Sits quietly in your system tray, keeping your Discord status updated with live Spotify lyrics — no installer, no fuss.

Windows 10 or later  ·  Spotify account  ·  Discord account
Setup
1

Get a Spotify Client ID

Go to developer.spotify.com, create a new app, and add the following redirect URI:

lyricpresence://callback

Copy your Client ID from the app dashboard.

2

Get your Discord token

Open Discord in a browser, open DevTools (F12), go to the Network tab, send any message, and find a request with an Authorization header. Copy that value.

Never share your Discord token — anyone with it has full access to your account.
3

Download & run

Download the latest release from GitHub. No installer is needed — just run the executable. LyricPresence will appear in the system tray.

4

Configure the app

Right-click the tray icon → Settings. Paste your Spotify Client ID and click Connect Spotify. Then paste your Discord token.

5

Start

Right-click the tray icon → Start. Play a track on Spotify and your Discord status will begin updating immediately.

Troubleshooting

Discord status not changing

Double-check your Discord token — tokens expire if you change your password or log out of all devices.

"Nothing playing" even though Spotify is open

Make sure Spotify is actively playing (not paused) and that the correct API scopes were granted during the Spotify login.

No lyrics showing for a song

Lyrics come from LRCLIB. If no time-synced lyrics are available for that track, the status won't update for that song.

"Connect Spotify" fails

Make sure lyricpresence://callback is added exactly as a redirect URI in your Spotify developer dashboard.
