Under the hood

How it works.

1

Spotify Web API

Polls your currently playing track using your own Spotify Client ID and OAuth token.

2

LRCLIB Lyrics

Fetches free, time-synced lyrics from LRCLIB — a community-maintained open database.

3

Line-by-line sync

Displays the correct lyric line at the exact millisecond, matching the Spotify playback position.

4

Discord Status

Pushes each line to your Discord custom status using your account token.
